## Response times

I read everything. GitHub issues are usually triaged within a day or two; email may take a little longer. For urgent bugs, a GitHub issue with reproduction steps is the fastest path to a fix.

## Security

If you believe you've found a security vulnerability in Postmate Client, please **do not open a public issue**. Email <a href="mailto:help@postmateclient.com">help@postmateclient.com</a> with the details and I'll respond as quickly as possible.
